# 葵花码使用说明

## 1. 先选择内容来源

- **网页链接**：粘贴完整的 `https://` 或 `http://` 网址，点击“生成葵花码”。也可以点击“试试示例”体验。
- **上传二维码**：选择一张图片，或拖入图片、粘贴截图。识别后自动生成，不需要再点一次生成。

二维码图片支持 PNG、JPG、WebP，最大 10 MB、4000 万像素。图片应包含一个清晰完整的普通方形二维码，内容必须是网页链接。识别成功后可点击“查看链接”检查或编辑原网址。

## 2. 调整外观

点击“添加头像”选择图片；图片会自动居中裁剪，点击“移除”恢复默认图案。头像支持 PNG、JPG、WebP，最大 10 MB。

图片尺寸默认为 1024 × 1024，适合大多数分享场景。可以选择 512 或 2048。调整头像和尺寸会自动更新已有图片。

“高级设置”默认收起。保留“自动选择”即可。射线有 36、54、72 条；纠错有 L、M、Q、H。射线越多，容量通常越大；纠错越高，可容纳的数据越少。修改射线或纠错后需要重新生成。

## 3. 保存与分享

- **下载 PNG**：适合聊天分享、文档插图和大多数使用场景。
- **下载 SVG**：适合设计排版、放大和印刷，头像仍为位图。
- **复制图片**：把 PNG 复制到剪贴板，需要浏览器支持并允许权限；推荐使用 HTTPS 或 localhost。

桌面端在右侧预览与保存，手机端在输入区域下方，生成成功后自动移到预览区域。生成前或修改内容后，下载按钮会暂时禁用，避免保存旧图片。出错时按页面提示处理后重新生成。

分享前请用实际使用的微信或扫码器测试图片，并确认最终网页可以打开。

## 4. 网址太长怎么办

超出编码容量的网址需要先转为短链接，生成的葵花码保存的是短链接。原始网址和参数会完整提交给 Ace Data，扫码后由短链服务跳转至原网址。

展开“高级设置”，点击“自动转链设置”：

- **站点已配置**：超长链接会自动转链，无需额外操作。
- **站点未配置**：填写自己的 Ace Data Token。Token 只保存在当前页面内存，刷新后清除。

站点维护者也可以在服务器配置服务，访客无需填写 Token。额度、计费和短链有效期以服务商规则为准。没有配置时，容量内链接和二维码转换仍可正常使用。

## 5. 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 提示协议不支持 | 使用 http:// 或 https:// 网页链接。小程序分享口令和普通文字不支持。 |
| 未识别到二维码 | 使用清晰原图，保留二维码周围空白；截图过大时先裁剪。 |
| 识别出非链接内容 | 换成包含网页地址的二维码，Wi-Fi 配置等内容不能转换。 |
| 短链接仍超过容量 | 将射线与纠错都恢复为自动选择。 |
| 转链失败 | 检查网络、Token 和账号余额；稍后重试。 |
| 提示频繁请求 | 至少等待一分钟，避免连续重复提交。 |
| 复制失败 | 允许剪贴板权限，或直接下载 PNG。 |
| 短链打不开 | 在目标网络、浏览器和微信中测试短链及原网页。 |

## 6. 隐私与数据

二维码识别、头像裁剪和图片生成都在浏览器本地完成，图片不上传。只有超容量的网址在生成时会提交给转链服务。

本页面不保存输入历史或头像。成功短链仅在当前页面内存缓存，最多 256 条；刷新清除。清空页面缓存不代表第三方删除已经生成的短链。

个人 Token 不写入图片或浏览器持久存储。自行部署公开网站时，应在服务端配置密钥，具体见项目部署文档。

## 7. 识别范围

输入图片识别支持普通 QR Code，不解析微信专用小程序码。内部编码回读通过，不代表所有微信版本或网络已经验证可用。
