# 邀请制版本验收记录

验证环境：2026-11-04，Node.js 22、Miniflare 4.20260730.0 / workerd、Chromium、Python Playwright。当前转链实现已更新为浏览器直连；下方分日期记录区分早期服务端实测。对象为 `feature/invite-console`，不代表 main 生产环境已经升级。

## 自动化验证

- 编码：5 组测试，包含 120 个兼容基准；矩阵、参数、Unicode、容量拒绝与回读保持原行为，未扩大 72 条射线上限。
- 账号与权限：一次性邀请并发注册、重复账号回滚、过期 / 撤销邀请、登录与管理员权限、同源写请求、超大请求、账号停用、改密撤销会话、会话过期、登录限流、管理员初始化不重置旧密码。
- 历史与用量：真实本地 D1/R2 下的生成、图片所有者隔离、幂等重试、相同请求并发提交、外观修改不计数、转链失败不计数、分页和北京时间日期统计。
- 存储故障：在本地 D1/R2 外注入 R2 写入失败和 D1 提交后响应丢失，确认失败不计数、已提交的图片不被误删；缺失资源绑定时拒绝服务。
- 浏览器完整流程：管理员初始化 → 创建邀请 → 用户注册登录 → 生成与头像修改 → 历史 PNG/SVG 下载 → 二维码长链接生成 → 后台统计 → 邀请重复使用失败 → 账号停用 / 启用 → 重新登录后历史保留。
- 响应式：320、390、768、1440 像素宽度检查，查看桌面后台和移动端历史截图。
- 构建：整个站点通过 Worker 路由鉴权；静态输出不包含编码核心源码、环境文件或真实 Token。
- 依赖：Miniflare 的 sharp / undici 使用兼容版本覆盖修复已知问题，`npm audit` 无已知漏洞。

测试命令见 README。浏览器及转链接口回归使用模拟 Ace Data 响应，不消耗真实账号额度。当前浏览器直接请求 Ace Data，使用 `redirect: 'error'` 阻止重定向；Functions 不再请求该接口。

## 验证边界

- 没有配置线上 D1/R2、执行线上迁移或把此版本部署到生产；上线后仍需按 README 完成绑定和完整验收。
- 真实浏览器本地网络下验证了 Ace Data 调用成功；未证明国内所有网络可达、短链长期有效或 Cloudflare 线上配置正确。
- 未单独验证 Safari、Firefox、Edge，内部回读不能替代目标微信版本实机扫码。
- 商业授权仍存在 NOTICE 中列明的待确认范围。

## 2026-11-05 转链回归

本地保存的 Token 分别通过直接请求及 workerd 请求真实 Ace Data，均获得 HTTP 200；观察到 `/编号` 和 `/r/编号` 两种短链形式。增加兼容及上游状态区分后，11 组自动测试全部通过，包含真实本地 D1/R2 下的成功保存、失败不计数和上游响应脱敏。

这两次实测不代表新线上站点的 Secret 已验证；线上报错仍需按部署文档核对状态和配置。

## 2026-11-05 浏览器直连验收

- 真实 Chromium 页面登录后提交超容量网址：浏览器向 Ace Data 发起一次 HTTPS POST（HTTP 200），随后服务端生成返回 201，PNG 下载与历史图片读取成功，历史增加一条。
- 浏览器直接请求无需服务端转发；容量预检查返回 422 / SHORTEN_REQUIRED，既不写记录也不增加统计；二次生成沿用同一个请求标识。
- 自动化覆盖配置接口的登录与同源保护、原网址与短链分别保存、非法短链拒绝、重复请求和客户端 401/402/403/429/500、网络失败、取消请求不会保存迟到结果。
- Token 不在源码、静态构建或浏览器持久存储，但对已登录浏览器可见；新模式的限制见 SECURITY.md。
