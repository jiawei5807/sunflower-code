# 验收记录

验证环境：2026-11-04，Node.js 22、Chromium、Python Playwright。

## 自动化验证

- 编码测试：5 组，含 120 个行为基准。协议容量、矩阵回读、参数错误与 Unicode 链接保持兼容。
- 服务接口：4 组，覆盖固定上游、服务端 Token、同源限制、无效网址、超大请求、限流、异常上游及敏感文件不可访问。
- 浏览器流程：链接输入、示例、头像上传与移除、尺寸与纠错、PNG/SVG 下载、剪贴板回读、输入变更后旧导出禁用。
- 短链流程：缺失配置提示、个人 Token 配置、JSON 请求、缓存、错误与超时、取消旧任务、重复提交、静态文件运行。
- 二维码：PNG/JPEG/WebP、旋转、反色、截图、中文链接、长链接转链、错误图片与内容、多次上传及旧结果隔离。
- 用户体验：空白/错误/待生成/成功状态、手机生成后预览定位、键盘标签页、拖放与粘贴、设置对话框、Token 清除、不写入持久存储。
- 响应式：320、390、768、1024、1440 像素宽度；文档导航及锚点；桌面和手机截图人工查看。

浏览器回归使用模拟转链响应，不消耗真实账号额度。此前真实 Ace Data 接口已经验证 HTTP 200 与短链 302 跳转；重构后的同源转链已实时验证 HTTP 200、SVG 内容与短链一致，浏览器未发送 Authorization 或直接请求服务商。

## 边界

- 内部回读和桌面浏览器跳转不能证明微信实机扫码、国内手机网络可达性或服务商长期可用。
- 未单独验证 Safari、Firefox 或 Edge。
- 未发布至 GitHub、npm 或公网。
- 协议兼容数据和默认图标仍待再分发授权，见 NOTICE。MIT 只覆盖项目原创贡献。

页面精简：移除顶部介绍、底部品牌/隐私提示和导出说明；自动转链配置收进高级设置，错误时仍可直接打开配置。

主题更新：天蓝色背景、白色面板、蓝色操作按钮与选中状态，文档与弹窗同步配色；生成图片的协议、中心和角标保持原样。

## Cloudflare Pages 适配

- Pages Functions 使用高级模式 `_worker.js`，构建生成仅包含 `/config.js`、`/api/shorten` 的路由配置。
- 4 组 Worker 单元测试通过：静态资源回退、运行时机密使用、同源检查、内容校验、请求体上限、限流和上游错误。
- 浏览器模拟 Pages 配置验证：转链无需用户配置，Token 入口隐藏，浏览器同源请求不携带 Authorization。构建产物不含本地真实 Token。
- 本次未登录 Cloudflare 或部署线上项目；Pages 实际运行与机密绑定需按 README 部署后验证。
